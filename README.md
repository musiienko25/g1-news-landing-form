# G1 News Landing Form

A simple landing page with a subscription/data collection form for a news service. The project focuses on a fast, lightweight UI and basic user interaction without heavy dependencies.

## 🚀 Demo

You can run it locally in seconds without any build step:

```bash
python3 -m http.server 5500
```

Then open in your browser:

```
http://localhost:5500
```

## 📌 Features

* Lightweight and fast layout
* Responsive design (mobile-friendly)
* Simple UI for data collection (form)
* Minimal dependencies — pure HTML/CSS/JS
* Can be used as a starter template for landing pages

## 🛠 Technologies

* HTML5
* CSS3 (Flexbox / Grid)
* JavaScript (vanilla)

## ▶️ How to Run

### Option 1 (recommended)

```bash
python3 -m http.server 5500
```

### Option 2 (Node.js)

If you have Node.js installed:

```bash
npx serve .
```

or

```bash
npx live-server
```
